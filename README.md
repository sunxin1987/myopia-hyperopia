# 近视与远视的成因及矫正模拟

互动模拟：按八年级上册教材第 4 章第 5 节《透镜的应用》（图 4–5–2～图 4–5–6）做的近视、远视成因与矫正模拟实验。

在线使用：https://sunxin1987.github.io/myopia-hyperopia/

## 能试什么

- **三种眼睛**：正常眼 / 近视眼 / 远视眼，对照着看像的位置有什么不同。
- **两种成因**（课本原话）：近视——晶状体焦距偏短，或眼轴偏长；远视——晶状体焦距偏长，或眼轴偏短。
- **拖动物体**：看远处（6 m）和看近处（25 cm，明视距离）时像的变化。
- **戴眼镜矫正**：近视戴凹透镜、远视戴凸透镜；可以自己调度数，也可以点“一键配到合适度数”。
- **视网膜上的像**：像落在视网膜上就是清晰的，落在前面或后面就是一片模糊的光斑。
- **自主活动 · 自制水透镜**：注水、抽水改变水透镜的焦距，找让光屏上的像最清晰的水量，模拟睫状肌调节。
